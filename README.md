### SubCounter

**A cloud backend that connects a physical subscriber display to an authorized YouTube Studio channel**

I built the Cloudflare backend, account dashboard, and ESP32 firmware. The system pairs counters to customer accounts, collects channel counts, and pushes updates and display settings over authenticated WebSockets.

- Shared source collection across displays, with database leases and account-scoped Durable Objects.
- Complete reconnect snapshots, offline count retention, and device credential revocation.
- Per-device appearance controls, Wi-Fi onboarding, native firmware tests, and disposable backend integration checks.

**Technology:** JavaScript, Cloudflare Workers, D1/SQLite, Durable Objects, WebSockets, C++, ESP32, and FreeRTOS.

[Technical case study](case-studies/subcounter.md) · [SubCounter](https://subcounter.app/) · [Dashboard](https://my.subcounter.app/)

The source is private. Customer invitation activation and physical setup/update validation remain ongoing.
