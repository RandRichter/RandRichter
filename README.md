## Featured project

### Display Tips

**Livestream tip alerts for creators using OBS**

I built Display Tips to bring PayPal, Venmo, and Cash App tip alerts into an OBS browser source. The product includes creator onboarding, account connections, configurable overlays, dashboards, subscription billing, and affiliate workflows.

**My work**

- Built the creator-facing website, dashboards, and overlay interfaces.
- Implemented payment-event verification, transaction deduplication, and real-time alert delivery.
- Built connected-account and inbox workflows, alongside billing and administrative tools.
- Developed automated tests for account flows, billing, event delivery, and UI behavior.

**Technology:** JavaScript, HTML/CSS, Cloudflare Workers, Python/FastAPI, OAuth integrations, and automated testing.
